# 在 IDEA 里安装 / 更新「摸鱼小说阅读器」插件

这个插件是**本地打包装载**的，不上 JetBrains 插件市场。所以「更新」本质就是：
**用新版本的 zip 覆盖重装一次**。整个过程 1 分钟搞定。

---

## 一、先找到最新的安装包

每次改完代码，都会在下面这个目录生成一个新的 zip：

```
C:\Users\dell\WorkBuddy\2026-09-16-09-28-25\idea-novel-reader\build\dist\
```

文件名带版本号，**认版本号最大的那个**，例如当前最新是：

```
idea-novel-reader-1.0.17.zip
```

> 目录里会积累一堆历史版本（1.0.3 ~ 1.0.17），别装错了——**装数字最大的**。

---

## 二、在 IDEA 里安装（覆盖旧版 = 更新）

### 步骤 1：打开插件设置

顶部菜单栏依次点：

```
File  →  Settings...   （macOS 是 IntelliJ IDEA → Settings...）
```

或者直接按快捷键 **`Ctrl + Alt + S`**。

### 步骤 2：进入 Plugins 页面

在设置窗口左侧列表里，点 **Plugins**（插件）。

### 步骤 3：从磁盘安装

点 Plugins 页面**右上角的齿轮图标（⚙）**，在弹出的菜单里选：

```
Install Plugin from Disk...   （从磁盘安装插件）
```

### 步骤 4：选中 zip 文件

在弹出的文件选择框里，找到第一步那个最新版本的 zip：

```
idea-novel-reader-1.0.17.zip
```

选中它，点 **OK**。

### 步骤 5：重启 IDEA

安装完成后，IDEA 会提示需要重启才能生效（右下角弹一个「Restart IDE」按钮），
点 **Restart** 重启即可。

> 如果装的是新版本覆盖旧版本，IDEA 也会要求重启。

---

## 三、装完后怎么确认装上了

重启后：

1. 看**右侧边栏**有没有一个「摸鱼小说」的工具窗图标（平时缩成小图标）。
2. 顶部 **Tools** 菜单里，有没有「打开本地小说…」「代码弹出框阅读」这些项。
3. 按快捷键 **`Ctrl + Alt + Shift + X`**，能弹出老板键（隐身/还原）就说明插件活了。

---

## 四、常用快捷键速查（1.0.17 版）

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + Alt + Shift + R` | 代码弹出框阅读：弹输入框填秒数 → 一句一行自动换句，再按一次关闭 |
| `Ctrl + Alt + Shift + X` | 老板键：一键伪装成工作界面 |
| 小键盘 `+` / `-` | 全局翻上一句 / 下一句（鼠标在哪都能翻） |
| `Ctrl + Alt + →` / `←` | 下一章 / 上一章 |
| 弹窗内 `S` | 改自动换句的秒数 |
| 弹窗内 `空格` | 暂停 / 继续自动换句 |
| 弹窗内 `Esc` | 关闭弹窗 |

## 五、常见问题

### Q1：装完没反应 / 右侧没有工具窗图标？
去 `View → Tool Windows` 里找「摸鱼小说」点开；或者 `File → Settings → Plugins`
确认「摸鱼小说阅读器」是 **Enabled**（勾选）状态。

### Q2：快捷键按了没反应？
八成是键位冲突。去 `File → Settings → Keymap`，右上角搜索框输入
**「代码弹出框阅读」**，能看到当前绑定，自己改一个顺手的键即可。

### Q3：怎么卸载？
`File → Settings → Plugins`，在已安装列表里找到「摸鱼小说阅读器」，
点旁边的 **Disable**（停用）或 **Uninstall**（卸载）。

### Q4：装了新版，旧版的历史进度还在吗？
在。阅读进度、书架、设置都持久化在 IDEA 的配置目录里
（`ideanovel.xml`），覆盖重装不会丢。

## 六、开发者自己重新打包（可选）

如果你改了代码想重新打一个包：

```bash
# 用托管版 Python 跑打包脚本，--version 指定版本号
python tools/package_local.py --version 1.0.18
```

产出 `build/dist/idea-novel-reader-1.0.18.zip`，再按上面的「二」装一遍即可。
